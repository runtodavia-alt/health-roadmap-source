# 나의 건강 로드맵

체중과 체지방률, 명상, 식사, 컨디션 메모를 날짜별로 기록하고 주간·월간으로 돌아보는 웹앱입니다.

## 사용 방법

1. 날짜를 고르고 기록할 항목을 입력한 뒤 **기록 저장**을 누릅니다.
2. 아래의 **지난 기록 보기 · 수정**에서 저장한 기록을 고치거나 삭제합니다.
3. 기록과 돌아보기 내용은 현재 브라우저의 `localStorage`에 저장됩니다. 서버로 전송되거나 다른 기기와 동기화되지 않습니다.

브라우저의 사이트 데이터나 저장 공간을 지우면 기록도 함께 삭제됩니다. 다른 사람과 기기를 같이 쓰는 경우 기록을 저장하지 마세요.
